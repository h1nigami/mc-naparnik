# Напарники

Самообучающиеся напарники для Minecraft. Каждым управляет небольшая нейросеть, веса которой
подбирает генетический алгоритм — без обучающих данных и библиотек машинного обучения, на
чистой Java. Напарники живут в твоём мире, ходят, копают, подбирают дроп, строят, дерутся с
мобами и друг с другом, гибнут, возрождаются и от жизни к жизни становятся лучше.

К ним прилагается локальная панель: настройка наград и разрешённых действий, фоновое обучение
на нескольких процессах и живой мониторинг того, что делает каждый напарник в игре.

## Что умеет

- **Учится прямо в игре.** Популяция мозгов проживает настоящие жизни в твоём мире; удачная жизнь
  сразу даёт потомка на место худшей особи.
- **Учится в фоне.** Параллельные процессы-«острова» прогоняют тысячи жизней в секунду в упрощённом
  симуляторе и обмениваются лучшими мозгами. Удачный мозг одной кнопкой выкатывается в игру.
- **Взаимодействует с миром.** Ломает блоки с настоящим дропом, подбирает свои и брошенные тобой
  предметы, строит из собранного, дерётся, ест, крафтит кирки.
- **Настраивается без перезапуска.** Награды, разрешённые действия, цели для удара, темп и параметры
  эволюции меняются в панели и подхватываются игрой за секунду.
- **Показывает, о чём думает.** Над головой каждого напарника — текущее решение, в панели — полная
  статистика каждой жизни.

## Как устроено

Прямой связи между панелью и игрой нет: всё общается через файлы в каталоге `~/.naparnik`.
Поэтому любую часть можно закрыть и открыть независимо — остальные продолжат работать.

```
        MINECRAFT 26.2                                  ПАНЕЛЬ (127.0.0.1:8765)
 ┌──────────────────────────────┐                ┌──────────────────────────────┐
 │ мод «Напарник» (Fabric)      │                │ Python, только stdlib        │
 │ каждые 10 тиков:             │  stats.json →  │ обзор · острова · игра ·     │
 │  мир → 25 чисел → мозг →     │                │ настройки                    │
 │  действие                    │ ← config       │                              │
 │                              │ ← brain.json   │ запускает ↓                  │
 └──────────────────────────────┘                └──────────────┬───────────────┘
                                                                ▼
                                                  ОСТРОВА — процессы Java,
                                                  генетика в симуляторе
```

| Каталог | Что внутри |
|---|---|
| `trainer/` | мозг, симулятор, генетический алгоритм, острова, проверки — чистая Java без зависимостей |
| `mod/` | Fabric-мод: напарник в игре, эволюция в мире, статистика, приём мозга из панели |
| `panel/` | локальная панель: `server.py` и одна страница `index.html` |
| `run.sh` | проверки и обучение из командной строки |
| `Напарники.command` | запуск панели двойным кликом (macOS) |

`Brain.java`, `Genome.java`, `Sim.java`, `Evolve.java` и `Config.java` лежат в `trainer/` и в
`mod/` одинаковыми копиями: веса обучаются в одном месте и означают в игре ровно то же самое.

## Установка

### 1. Java 25

Нужна JDK 25 — под неё собирается Minecraft 26.2. Удобнее всего положить её прямо в проект, тогда
все скрипты найдут её сами:

```sh
mkdir -p .jdk
# macOS, Apple Silicon; для другой платформы поменяй mac/aarch64 в адресе
curl -L -o .jdk/jdk25.tar.gz \
  "https://api.adoptium.net/v3/binary/latest/25/ga/mac/aarch64/jdk/hotspot/normal/eclipse"
tar xzf .jdk/jdk25.tar.gz -C .jdk
```

Подойдёт и уже установленная JDK 25 — достаточно задать `JAVA_HOME`.

### 2. Minecraft 26.2 с Fabric

1. Поставь **Fabric Loader** для 26.2 — через лаунчер (в TLauncher это отдельная версия «Fabric
   26.2») или официальным установщиком с [fabricmc.net](https://fabricmc.net/use/installer/).
2. Скачай **Fabric API** для 26.2 с [Modrinth](https://modrinth.com/mod/fabric-api) и положи в
   папку `mods` игры.

Папка игры: macOS — `~/Library/Application Support/minecraft`, Windows — `%APPDATA%\.minecraft`,
Linux — `~/.minecraft`.

### 3. Сборка мода

```sh
cd mod
JAVA_HOME="$(ls -d ../.jdk/jdk-25*/Contents/Home 2>/dev/null || ls -d ../.jdk/jdk-25*)" ./gradlew build
```

Готовый файл — `mod/build/libs/naparnik-1.0.0.jar`. Первая сборка скачивает Minecraft и
занимает несколько минут.

### 4. Установка мода

Скопируй `naparnik-1.0.0.jar` в папку `mods` рядом с Fabric API и **перезапусти игру**:
загруженный код на лету не подменяется.

Мод загрузился, если в журнале игры есть строка `Напарник загружен, весов в мозге: 416`.

## Игра

| Команда | Что делает |
|---|---|
| `/naparnik spawn` | призвать напарника рядом с собой (до 8 одновременно) |
| `/naparnik status` | поколение, рекорд и состояние каждого напарника |
| `/naparnik remove` | убрать всех напарников; популяция сохраняется |
| `/naparnik speed <тиков>` | темп решений: 10 — два в секунду, 1 — двадцать |
| `/naparnik control` | включить или выключить ручное управление первым напарником |

Напарник выглядит как житель с табличкой вида `Напарник 3·7 · копает`: поколение, номер особи и
текущее решение. Когда жизнь заканчивается — гибель или конец срока, — в чат приходит её итог, а
на том же месте появляется следующая особь.

> **Внимание.** Напарник ломает блоки. Не призывай его рядом с постройками, которыми дорожишь.

**Одиночный мир живёт, только пока ты в нём.** Вышел в меню — мир замирает целиком, это
поведение самой игры. Чтобы напарники учились без тебя, нужен [выделенный
сервер](#выделенный-сервер-чтобы-учились-без-тебя).

## Панель

```sh
python3 panel/server.py
```

и открыть `http://127.0.0.1:8765`. На macOS то же самое делает двойной клик по
`Напарники.command`.

| Вкладка | Что там |
|---|---|
| Обзор | рекорды фонового обучения и игры, число работающих островов, какой мозг сейчас в игре, графики |
| Фоновое обучение | запуск и остановка островов, их поколения, рекорд и медиана, кнопка «В игру» |
| Игра | напарники в реальном времени: текущее действие, жизнь, что сломали, подняли, построили, кого побили |
| Настройки | разрешённые действия, цели для удара, все награды, темп, параметры эволюции |

Панель не хранит своего состояния — её можно закрыть в любой момент.

## Фоновое обучение и выкладка в игру

1. Вкладка **Фоновое обучение** → укажи число островов → **Запустить**. Каждый остров — отдельный
   процесс со своей популяцией; раз в пять поколений острова обмениваются лучшими мозгами.
2. Следи за **медианой**: она показывает, подтянулась ли вся популяция. Единичный рекорд бывает
   везением.
3. Нажми **В игру** у удачного острова. Мод заметит новый мозг за пару секунд и перестроит
   популяцию вокруг него — в чате придёт сообщение.

То же из командной строки:

```sh
./run.sh train 200 400 2400     # популяция, поколений, тиков на жизнь → brain.json
```

## Настройки

Все настройки — в `~/.naparnik/config.properties`. Их правит панель, а читают острова и игра.
Файл создаётся со значениями по умолчанию при первом запуске.

| Ключ | По умолчанию | Смысл |
|---|---|---|
| `action.0` … `action.7` | 1 | разрешены ли действия: вперёд, влево, вправо, копать, ставить, бить, есть, крафт |
| `attack.monsters` | 1 | бить враждебных мобов |
| `attack.rivals` | 1 | бить других напарников |
| `attack.animals` | 0 | бить мирных животных |
| `attack.players` | 0 | бить игроков |
| `faceEnemyRange` | 4 | ближе этого расстояния напарник сам разворачивается к враждебному мобу; 0 — выключить |
| `life` | 240 | длина жизни в решениях |
| `decisionEvery` | 10 | игровых тиков на одно решение |
| `explore` | 0.2 | доля случайных ходов с перекосом в копку и бой |
| `sight` | 10 | дальность обзора в блоках |
| `population` | 20 | размер популяции |
| `randomTail` | 8 | сколько особей засевается случайно — против схлопывания в один геном |
| `mutationRate` | 0.03 | доля мутирующих весов потомка |
| `mutationSigma` | 0.25 | сила мутации |
| `tournament` | 3 | размер турнира при выборе родителя |
| `seeds` | 3 | на скольких картах проживает особь на острове |
| `reward.age` | 0.2 | за прожитое решение |
| `reward.visited` | 15 | за новую клетку |
| `reward.mined` | 200 | за сломанный блок (свои поставленные не считаются) |
| `reward.picked` | 30 | за подобранный предмет |
| `reward.built` | 60 | за постройку в новой клетке; блок, приставленный к своим, — втрое |
| `reward.sheltered` | 20 | за решение под крышей с тремя стенами |
| `reward.hits` | 50 | за попадание |
| `reward.kills` | 300 | за убийство |
| `reward.rivals` | 500 | за победу над напарником, сверх убийства |
| `reward.repertoire` | 100 | за каждое новое освоенное действие |
| `reward.tech` | 5000 | за уровень кирки |
| `reward.wasted` | −5 | за пустое действие |

## Выделенный сервер: чтобы учились без тебя

1. Скачай серверный Minecraft 26.2 и поставь на него Fabric установщиком в режиме `server`.
2. Положи в `mods` сервера `naparnik-1.0.0.jar` и Fabric API.
3. В `server.properties`:
   ```properties
   pause-when-empty-seconds=0   # иначе сервер 26.2 засыпает через минуту без игроков
   online-mode=false            # если заходишь с аккаунта без лицензии
   ```
4. Встань у будущей базы напарников и выполни `/forceload add ~-3 ~-3 ~3 ~3`: сущности в
   выгруженных чанках не живут, и без этого напарник «спит», пока тебя нет.

## Ручное управление

`/naparnik control` передаёт первого напарника внешней программе. Файлы лежат в папке мира:

- `naparnik-view.txt` — что напарник видит: позиция, здоровье, блок впереди, ближайшие дерево,
  руда, цель и предмет, сумка;
- `naparnik-command.txt` — очередь ходов, по одному в строке: `вперёд`, `влево`, `вправо`,
  `копать`, `ставить`, `бить`, `есть`, `крафт`. Мод исполняет их по порядку и удаляет файл.

Повторная `/naparnik control` возвращает управление мозгу.

## Мозг напарника

Персептрон **25 → 12 → 8** с активацией ReLU. Геном — 416 весов.

**Входы** (все в диапазоне −1…1):

| # | что |
|---|---|
| 0–1 | здоровье, сытость |
| 2–3 | время суток (синус и косинус) |
| 4–6 | впереди твёрдый блок · его можно сломать сейчас · это бревно |
| 7–9 | ближайшее дерево: близость, синус и косинус угла |
| 10–12 | ближайшая руда (камень, с каменной киркой — железо) |
| 13–15 | ближайшая разрешённая цель для удара |
| 16–18 | ближайший лежащий предмет |
| 19–21 | можно скрафтить · блоков в сумке · еды в сумке |
| 22–24 | его бьют прямо сейчас · можно запрыгнуть вперёд · сколько стен вокруг |

**Выход** — самое сильное из **выполнимых прямо сейчас** действий. «Ставить» с пустой сумкой,
«крафт» без ресурсов или удар в пустоту мозг не выбирает вовсе; третий поворот подряд тоже
запрещён, чтобы не кружиться на месте.

**Бой.** Удар засчитывается только по цели перед собой, в конусе ±60°, и не чаще раза в секунду
игрового времени. Только что появившийся напарник первые 20 решений неприкосновенен.

**Отбор.** В игре — стационарный: как только жизнь лучше худшей в популяции, её потомок
(равномерный кроссовер с партнёром из турнира и гауссова мутация) сразу занимает место худшей
особи. На островах — поколенческий с элитизмом и миграцией между островами.

## Проверки

```sh
./run.sh check
```

Семь проверок падают, если сломана любая опора: детерминизм симулятора, копка, лестница крафта,
гибель от бездействия, запись и чтение мозга, закрытая лазейка «поставил–сломал» и то, что отбор
действительно улучшает популяцию.

## Замеры и находки

Самое интересное в проекте — не то, что напарник научился, а то, как именно обучение ломалось.

| Проблема | Как проявлялась | Что помогло |
|---|---|---|
| Плоская награда | вся популяция гибла от голода на одном тике с одинаковым фитнесом — отбору не за что зацепиться | награда за исследование новых клеток |
| Немой вход | при 42 добытых брёвнах кирка так и не крафтилась: счётчик дерева в сенсоре насыщался и молчал | вход «крафт доступен» |
| Невыполнимые действия | 44% решений впустую, треть популяции тратила 60–100% ходов на «ставить» без блоков и «крафт» без ресурсов | маска выполнимых действий: **0% впустую, в 2.2 раза больше клеток, в 2.7 раза больше добычи** на той же популяции |
| Накрутка награды | 111 «добыто» и 105 «построено» при 18 пройденных клетках — петля «поставил–сломал» | свой блок возвращается в сумку без награды, постройка засчитывается только в новой клетке: **123 клетки и железная кирка** за жизнь |
| Взаимоубийство | трое, появившись в одной точке, убивали друг друга за доли секунды — без сообщений о смерти | разворот только на враждебных мобов, неприкосновенность после появления, откат удара |

## Ограничения

- **Симулятор проще игры.** В нём нет лежащих предметов, ступенек и драки напарников между собой,
  поэтому фоновое обучение этим навыкам не учит — они развиваются только в игре. Замер: медиана
  островов выходит на плато за первые секунды.
- **У мозга нет памяти.** Сеть прямого распространения решает только по текущим 25 входам и не
  может «помнить», где уже искала.
- **Эволюция в игре медленная.** Одна жизнь — две минуты, поколение из 20 особей — около 40 минут
  на одного напарника. Нескольких напарников стоит держать одновременно: они учатся параллельно.
- **Разрыв версий.** Сборка рассчитана на Minecraft 26.2 с официальными маппингами Mojang; под
  другие версии имена классов придётся сверять заново.
