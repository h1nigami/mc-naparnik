# Напарники

Самообучающиеся напарники для Minecraft. Каждым управляет небольшая нейросеть, веса которой
подбирает генетический алгоритм — без обучающих данных и библиотек машинного обучения, на
чистой Java. Напарники живут в твоём мире, ходят, копают, подбирают дроп, строят, охотятся и
едят, дерутся с мобами и друг с другом, гибнут от голода, воды и в бою, возрождаются и от жизни к
жизни становятся лучше.

К ним прилагается локальная панель: настройка наград и разрешённых действий, фоновое обучение
на нескольких процессах и живой мониторинг того, что делает каждый напарник в игре.

## Что умеет

- **Учится прямо в игре.** Популяция мозгов проживает настоящие жизни в твоём мире; удачная жизнь
  сразу даёт потомка на место худшей особи.
- **Учится в фоне.** Параллельные процессы-«острова» прогоняют тысячи жизней в секунду в упрощённом
  симуляторе и обмениваются лучшими мозгами. Удачный мозг одной кнопкой выкатывается в игру.
- **Взаимодействует с миром.** Ломает блоки с настоящим дропом, подбирает свои и брошенные тобой
  предметы, строит из собранного, дерётся, ест, крафтит кирки.
- **Настраивается без перезапуска.** Награды, разрешённые действия, цели для удара, темп и параметры
  эволюции меняются в панели и подхватываются игрой за секунду.
- **Выживает как игрок.** Здоровье, сытость и воздух видны над головой и в панели; голод убивает,
  вода топит, мобы и соперники ранят настоящим уроном.
- **Добывает еду и не лезет в воду.** Голодным охотится на дичь и ест; в воду по своей воле не
  заходит, а попав — всплывает и выходит к берегу.
- **Не зависает.** Долгий простой штрафуется, зависших подталкивают, из ям строят лестницу наверх.
- **Показывает, о чём думает.** Над головой каждого напарника — текущее решение и рефлекс, в панели —
  полная статистика каждой жизни и арсенал: что лежит в сумке и что добыто.

## Как устроено

Прямой связи между панелью и игрой нет: всё общается через файлы в каталоге `~/.naparnik`.
Поэтому любую часть можно закрыть и открыть независимо — остальные продолжат работать.

```
        MINECRAFT 26.2                                  ПАНЕЛЬ (127.0.0.1:8765)
 ┌──────────────────────────────┐                ┌──────────────────────────────┐
 │ мод «Напарник» (Fabric)      │                │ Python, только stdlib        │
 │ каждые 10 тиков:             │  stats.json →  │ обзор · острова · игра ·     │
 │  мир → 30 чисел → мозг →     │                │ настройки                    │
 │  действие                    │ ← config       │                              │
 │                              │ ← brain.json   │ запускает ↓                  │
 └──────────────────────────────┘                └──────────────┬───────────────┘
                                                                ▼
                                                  ОСТРОВА — процессы Java,
                                                  генетика в симуляторе
```

| Каталог | Что внутри |
|---|---|
| `trainer/` | мозг, симулятор, генетический алгоритм, острова, проверки — чистая Java без зависимостей |
| `mod/` | Fabric-мод: напарник в игре, эволюция в мире, статистика, приём мозга из панели |
| `panel/` | локальная панель: `server.py` и одна страница `index.html` |
| `run.sh` | проверки и обучение из командной строки |
| `Напарники.command` | запуск панели двойным кликом (macOS) |

`Brain.java`, `Genome.java`, `Sim.java`, `Evolve.java` и `Config.java` лежат в `trainer/` и в
`mod/` одинаковыми копиями: веса обучаются в одном месте и означают в игре ровно то же самое.

## Установка

### 1. Java 25

Нужна JDK 25 — под неё собирается Minecraft 26.2. Удобнее всего положить её прямо в проект, тогда
все скрипты найдут её сами:

```sh
mkdir -p .jdk
# macOS, Apple Silicon; для другой платформы поменяй mac/aarch64 в адресе
curl -L -o .jdk/jdk25.tar.gz \
  "https://api.adoptium.net/v3/binary/latest/25/ga/mac/aarch64/jdk/hotspot/normal/eclipse"
tar xzf .jdk/jdk25.tar.gz -C .jdk
```

Подойдёт и уже установленная JDK 25 — достаточно задать `JAVA_HOME`.

### 2. Minecraft 26.2 с Fabric

1. Поставь **Fabric Loader** для 26.2 — через лаунчер (в TLauncher это отдельная версия «Fabric
   26.2») или официальным установщиком с [fabricmc.net](https://fabricmc.net/use/installer/).
2. Скачай **Fabric API** для 26.2 с [Modrinth](https://modrinth.com/mod/fabric-api) и положи в
   папку `mods` игры.

Папка игры: macOS — `~/Library/Application Support/minecraft`, Windows — `%APPDATA%\.minecraft`,
Linux — `~/.minecraft`.

### 3. Сборка мода

```sh
cd mod
JAVA_HOME="$(ls -d ../.jdk/jdk-25*/Contents/Home 2>/dev/null || ls -d ../.jdk/jdk-25*)" ./gradlew build
```

Готовый файл — `mod/build/libs/naparnik-1.0.0.jar`. Первая сборка скачивает Minecraft и
занимает несколько минут.

### 4. Установка мода

Скопируй `naparnik-1.0.0.jar` в папку `mods` рядом с Fabric API и **перезапусти игру**:
загруженный код на лету не подменяется.

При игре на выделенном сервере установи мод и на сервер, и на компьютеры игроков.

Мод загрузился, если в журнале игры есть строка `Напарник загружен, весов в мозге: 476`.

## Игра

| Команда | Что делает |
|---|---|
| `/naparnik spawn` | призвать напарника рядом с собой (до 8 одновременно) |
| `/naparnik status` | поколение, рекорд, здоровье, сытость, сумка и добыча каждого напарника |
| `/naparnik remove` | убрать всех напарников; популяция сохраняется |
| `/naparnik speed <тиков>` | темп решений: 10 — два в секунду, 1 — двадцать |
| `/naparnik control` | включить или выключить ручное управление первым напарником |

Напарник выглядит как Стив с табличкой вида `Напарник 3·7 · копает (охотится) · ❤16 · сыт 12`:
поколение, номер особи, текущее решение, рефлекс, здоровье и сытость; под водой — ещё и воздух. Когда жизнь заканчивается — гибель или конец срока, — в чат приходит её итог, а
на том же месте появляется следующая особь.

> **Внимание.** Напарник ломает блоки. Не призывай его рядом с постройками, которыми дорожишь.

**Одиночный мир живёт, только пока ты в нём.** Вышел в меню — мир замирает целиком, это
поведение самой игры. Чтобы напарники учились без тебя, нужен [выделенный
сервер](#выделенный-сервер-чтобы-учились-без-тебя).

## Панель

```sh
python3 panel/server.py
```

и открыть `http://127.0.0.1:8765`. На macOS то же самое делает двойной клик по
`Напарники.command`.

| Вкладка | Что там |
|---|---|
| Обзор | рекорды фонового обучения и игры, число работающих островов, какой мозг сейчас в игре, графики |
| Фоновое обучение | запуск и остановка островов, их поколения, рекорд и медиана, кнопка «В игру» |
| Игра | напарники в реальном времени: здоровье, сытость, воздух, текущее действие, добыча, простой, толчки, арсенал; от чего умирали |
| Настройки | разрешённые действия, цели для удара, все награды, темп, параметры эволюции |

Панель не хранит своего состояния — её можно закрыть в любой момент.

## Фоновое обучение и выкладка в игру

1. Вкладка **Фоновое обучение** → укажи число островов → **Запустить**. Каждый остров — отдельный
   процесс со своей популяцией; раз в 50 поколений остров берёт один лучший мозг у случайного соседа
   (при более частом обмене острова слипались в одинаковые копии).
2. Следи за **медианой**: она показывает, подтянулась ли вся популяция. Единичный рекорд бывает
   везением.
3. Нажми **В игру** у удачного острова. Мод заметит новый мозг за пару секунд и перестроит
   популяцию вокруг него — в чате придёт сообщение.

То же из командной строки:

```sh
./run.sh train 200 400 2400     # популяция, поколений, тиков на жизнь → brain.json
```

## Настройки

Все настройки — в `~/.naparnik/config.properties`. Их правит панель, а читают острова и игра.
Файл создаётся со значениями по умолчанию при первом запуске.

**Действия и цели**

| Ключ | По умолчанию | Смысл |
|---|---|---|
| `action.0` … `action.7` | 1 | разрешены ли действия: вперёд, влево, вправо, копать, ставить, бить, есть, крафт |
| `attack.monsters` · `attack.rivals` · `attack.animals` · `attack.players` | 1 · 1 · 1 · 0 | кого можно бить: мобов, других напарников, дичь, игроков |
| `faceEnemyRange` | 4 | ближе этого расстояния сам разворачивается к враждебному мобу; 0 — выключить |

**Жизнь, темп, эволюция**

| Ключ | По умолчанию | Смысл |
|---|---|---|
| `life` · `decisionEvery` | 240 · 10 | длина жизни в решениях; игровых тиков на решение |
| `explore` · `sight` | 0.2 · 10 | доля случайных ходов; дальность обзора в блоках |
| `population` · `randomTail` | 20 · 8 | размер популяции; сколько особей засевается случайно |
| `mutationRate` · `mutationSigma` · `tournament` | 0.03 · 0.25 · 3 | доля и сила мутации; размер турнира |
| `seeds` | 3 | на скольких картах проживает особь на острове (замер: 10 карт вдвое лучше против застоя) |
| `sim.trees` · `sim.lakes` · `sim.lakeSize` · `sim.animals` | 260 · 6 · 60 · 10 | мир островов: деревья, озёра, размер озера, дичь |

**Выживание и рефлексы**

| Ключ | По умолчанию | Смысл |
|---|---|---|
| `hunger.drainTicks` | 30 | тиков на единицу сытости — ускорено против игрока, чтобы голод значил что-то за двухминутную жизнь |
| `eat.below` · `hunt.below` · `hunt.range` | 10 · 14 · 24 | есть, когда сытость ниже; охотиться, когда ниже; видеть дичь на столько блоков |
| `water.avoid` | 1 | не заходить в воду с суши; попав — всплыть и к берегу |
| `stagnation.grace` · `kick.after` · `kick.length` | 15 · 25 · 6 | допуск простоя; толкнуть после стольких ходов без прогресса; длина толчка |
| `climb.after` | 20 | столько решений в яме со всех сторон — строить лестницу наверх; 0 — выключить |

**Награды**

| Ключ | По умолчанию | За что |
|---|---|---|
| `reward.age` · `reward.visited` | 0.2 · 15 | прожитое решение; новая клетка |
| `reward.mined` · `reward.wood` · `reward.picked` | 200 · 0 · 30 | сломанный блок (свои не в счёт); бревно отдельно; подобранный предмет |
| `reward.built` · `reward.sheltered` | 60 · 20 | постройка в новой клетке; решение под крышей с тремя стенами |
| `reward.hits` · `reward.kills` · `reward.rivals` | 50 · 300 · 500 | попадание; убийство; победа над напарником сверх убийства |
| `reward.hunt` · `reward.eat` | 300 · 50 | добытая дичь; съеденная еда |
| `reward.repertoire` · `reward.tech` | 100 · 5000 | новое освоенное действие; уровень кирки |
| `reward.wasted` · `reward.stagnation` · `reward.repeat` · `reward.kick` · `reward.death` | −5 · −3 · −20 · −50 · −1000 | пустое действие; ход простоя; повтор одного блока; толчок; смерть |

## Выделенный сервер: чтобы учились без тебя

1. Скачай серверный Minecraft 26.2 и поставь на него Fabric установщиком в режиме `server`.
2. Положи в `mods` сервера `naparnik-1.0.0.jar` и Fabric API.
3. В `server.properties`:
   ```properties
   pause-when-empty-seconds=0   # иначе сервер 26.2 засыпает через минуту без игроков
   online-mode=false            # если заходишь с аккаунта без лицензии
   ```
4. Встань у будущей базы напарников и выполни `/forceload add ~-3 ~-3 ~3 ~3`: сущности в
   выгруженных чанках не живут, и без этого напарник «спит», пока тебя нет.

## Ручное управление

`/naparnik control` передаёт первого напарника внешней программе. Файлы лежат в папке мира:

- `naparnik-view.txt` — что напарник видит: позиция, здоровье, блок впереди, ближайшие дерево,
  руда, цель и предмет, сумка;
- `naparnik-command.txt` — очередь ходов, по одному в строке: `вперёд`, `влево`, `вправо`,
  `копать`, `ставить`, `бить`, `есть`, `крафт`. Мод исполняет их по порядку и удаляет файл.

Повторная `/naparnik control` возвращает управление мозгу.

## Выживание и рефлексы

Всё, чего отбор не успевает выучить, пока особи гибнут, закрыто рефлексами. Мозг решает обычные
ходы, а рефлекс вмешивается, когда жизнь под угрозой.

- **Здоровье и голод как у игрока.** На нуле сытости — настоящий урон «голод» раз в 4 секунды до
  смерти; сытость 18 и выше лечит. Считается в игровых тиках, ускорение решений голод не ускоряет.
- **Вода.** Утопление ванильное, как у игрока: 15 секунд воздуха, потом 2 урона в секунду. Шагнуть
  в воду с суши нельзя; голова под водой — всплыть; ноги в воде — к ближайшему берегу до 16 блоков.
- **Еда.** Голоден и есть еда — ест. Голоден и в 24 блоках дичь — разворачивается, идёт к ней и бьёт;
  с убитых животных падает мясо, оно подбирается само.
- **Копка.** «Копать» ломает блок, который мешает пройти: на уровне головы, потолок над ступенькой
  или у ног. Раньше ломался только блок у ног, и из ямы напарник не выбирался никогда.
- **Ямы.** Высоко со всех четырёх сторон 20 решений подряд — строит лестницу наверх и продолжает,
  пока высоко хотя бы с трёх.
- **Простой и толчок.** Прогресс — новая клетка, добыча, постройка в новом месте, подобранный
  предмет, попадание. Долго без прогресса — штраф; ещё дольше — несколько ходов напарник идёт в
  открытую сторону сам.
- **Арсенал.** В панели и в `/naparnik status` видно, что лежит в сумке и что собрано за жизнь.

## Мозг напарника

Персептрон **30 → 12 → 8** с активацией ReLU. Геном — 476 весов. Мозги под меньшее число входов
при чтении расширяются нулевыми весами на новых входах и решают ровно так же, как до расширения, —
чемпионы и популяции переживают добавление входов.

**Входы** (все в диапазоне −1…1):

| # | что |
|---|---|
| 0–1 | здоровье, сытость |
| 2–3 | время суток (синус и косинус) |
| 4–6 | вперёд не пройти · есть что сломать · это бревно |
| 7–9 | ближайшее дерево: близость, синус и косинус угла |
| 10–12 | ближайшая руда (камень, с каменной киркой — железо) |
| 13–15 | ближайшая разрешённая цель для удара |
| 16–18 | ближайший лежащий предмет |
| 19–21 | можно скрафтить · блоков в сумке · еды в сумке |
| 22–24 | его бьют прямо сейчас · можно запрыгнуть вперёд · сколько стен вокруг |
| 25–26 | запас воздуха · впереди вода |
| 27–29 | ближайшая дичь |

**Выход** — самое сильное из **выполнимых прямо сейчас** действий; шаг в воду с суши выполнимым не считается. «Ставить» с пустой сумкой,
«крафт» без ресурсов или удар в пустоту мозг не выбирает вовсе; третий поворот подряд тоже
запрещён, чтобы не кружиться на месте.

**Бой.** Удар засчитывается только по цели перед собой, в конусе ±60°, и не чаще раза в секунду
игрового времени. Только что появившийся напарник первые 20 решений неприкосновенен.

**Отбор.** В игре — стационарный: как только жизнь лучше худшей в популяции, её потомок
(равномерный кроссовер с партнёром из турнира и гауссова мутация) сразу занимает место худшей
особи. На островах — поколенческий с элитизмом и миграцией между островами.

## Проверки

```sh
./run.sh check
```

Шестнадцать проверок симулятора. Каждая написана до кода и падает, если откатить то, что она
охраняет: детерминизм, копка, лестница крафта, гибель от бездействия, запись и чтение мозга,
лазейка «поставил–сломал» и штраф за повтор, толчок зависших, голод и утопление по часам игрока,
расширение мозга без смены решений, охота и еда, деревья не кормят, запрет воды и выход к берегу,
и то, что отбор действительно улучшает популяцию.

Живые проверки на выделенном сервере 26.2 (нужен каталог `server/` с сервером и модом):

| Скрипт | Что проверяет |
|---|---|
| `test-live.sh` | обычная жизнь нескольких напарников; `WALL=0` — без коробки из брёвен, `TEST_CONFIG` — свои настройки |
| `test-pit.sh` | шахта в коренной породе: выбираются ли только вверх |
| `test-survival.sh` | сухая арена: `MODE=adjacent` — охота рядом, `hunt` — охота на бродячих, `water` — выход из пруда |

## Замеры и находки

Самое интересное в проекте — не то, что напарник научился, а то, как именно обучение ломалось.

| Проблема | Как проявлялась | Что помогло |
|---|---|---|
| Плоская награда | вся популяция гибла от голода на одном тике с одинаковым фитнесом — отбору не за что зацепиться | награда за исследование новых клеток |
| Немой вход | при 42 добытых брёвнах кирка так и не крафтилась: счётчик дерева в сенсоре насыщался и молчал | вход «крафт доступен» |
| Невыполнимые действия | 44% решений впустую, треть популяции тратила 60–100% ходов на «ставить» без блоков и «крафт» без ресурсов | маска выполнимых действий: **0% впустую, в 2.2 раза больше клеток, в 2.7 раза больше добычи** на той же популяции |
| Накрутка награды | 111 «добыто» и 105 «построено» при 18 пройденных клетках — петля «поставил–сломал» | свой блок возвращается в сумку без награды, постройка засчитывается только в новой клетке: **123 клетки и железная кирка** за жизнь |
| Взаимоубийство | трое, появившись в одной точке, убивали друг друга за доли секунды — без сообщений о смерти | разворот только на враждебных мобов, неприкосновенность после появления, откат удара |
| Застой | лучший скакал 16 → 8.8 → 15.5 на тех же отложенных картах; добыча дерева стояла около 8 | 10 карт на особь вместо 3: **22 дерева**, при потолке эталона 42.6 |
| Зависание | 36% решений в простое, самый долгий простой 238 из 240 | штраф за простой и толчок: **16% и 126** на той же популяции |
| Подменённая причина смерти | «умер от голода» без единого сообщения игры — соседи убивали установкой здоровья в обход урона | удар настоящим уроном; причины сверены с сообщениями игры |
| Ямы | в шахте ни одна из 5 жизней не поднялась выше дна | копка головы и потолка, лестница наверх; ложных подъёмов на ровном месте — 0 |
| Вода | 4 из 4 утонули: шли по дну и рыли лестницу, которую заливало | всплытие и выход к берегу: **0 утоплений** |
| Слипание островов | у двух островов лучшие мозги совпали до последнего веса | миграция в 10 раз реже, одним мозгом |
| Вход-костыль | «запас воздуха» почти всегда равен +1 — эволюция сделала из него смещение, а не чувство воды | замер: заменить входы константой — фитнес ±0.4%, обнулить веса — −3…−6% |

## Ограничения

- **Симулятор двумерный.** В нём нет высоты, ступенек, лежащих предметов и драки напарников между
  собой; копку вверх, выход из ям и спасение из воды закрывают рефлексы, а не обучение.
- **Настоящих предметов не крафтят.** «Крафт» — только уровень кирки: деревянная, каменная, железная.
- **Рыбалки нет.** Рыбу напарник может только убить рядом; за ней в воду не пойдёт.
- **Дичь в игре не восстанавливается.** На островах стадо пополняется, в Minecraft мирные животные
  почти не появляются заново — съеденное стадо означает голод.
- **Чаще всего гибнут в драках друг с другом**, если бить соперников разрешено.
- **У мозга нет памяти.** Сеть прямого распространения решает только по текущим 30 входам.
- **Эволюция в игре медленная.** Одна жизнь — две минуты, поколение из 20 особей — около 40 минут
  на одного напарника.
- **Разрыв версий.** Сборка рассчитана на Minecraft 26.2 с официальными маппингами Mojang.
